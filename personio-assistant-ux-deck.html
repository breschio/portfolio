Personio Assistant:
UX Improvements

It's not how it looks — it's how it works.

Personio's AI Assistant had a 19% CSAT score. I shipped several improvements directly to production — becoming the first designer to commit code.

Role
Principal Product Designer
Timeline
May – December 2025
Team
PM, 1 FE Engineer, 7 ML Engineers

Context

AI was table stakes for deals. Customers wanted an AI strategy.

Personio built an AI Assistant for HR admins—headcount, retention, team trends. The company was early and aggressive on AI.

Context

The Mandate
1

Raise usability to industry standard

The assistant felt broken compared to competitors.

2

Connect UX to AI capabilities

The missing link between what the model could do and what users experienced.

3

No dedicated designer until me

Team of 7 ML engineers, 1 FE engineer. I was the first designer assigned.

Challenge

Beautiful Figma files. Broken production.

  • The shimmer incident — A fancy shader effect engineering couldn't render. Cycles burned while basic UX went unfixed.
  • Gradients never shipped — The assistant launched with flat colors instead.

Challenge

8 Problems
1

Input truncated questions

Single-line field hid text as users typed.

2

Static admin prompts

Employee launch coming—but prompts were still admin-focused.

3

Bottom-to-top response flow

Users scrolled against the content stream.

4

No stop, citations, or errors

Floating window blocked UI. No way to interrupt, verify, or debug.

19%
CSAT score in Q4. Second-lowest in the company. CEO and COO were the most vocal in the dogfooding channel. Team morale was rough.
"It's not how it looks—it's how it works."

Closing Figma-to-production gaps improves trust, even without model changes.
A designer who ships code moves faster than handoffs.

Journey

Learning to Ship

  • First fix — Background color on a card. Small scope, real code.
  • Felt guilty — Iterating in Cursor was so fast I felt guilty asking my engineer.
  • I knew I could do it — I'd been practicing at home. I just needed the chance.

Journey

The Pipeline

  • Hard part — Pipeline breaks. Complicated monolith. Learned to lean on engineering for rebasing and conflicts.
  • Milestone — First designer at Personio to commit production code.
  • 3-4 commits — Between July and October 2025.

Key Decisions

Why Input First

  • CEO Slack post — Frustrated with long text handling. Small enough to tackle, visible enough to matter.
  • Maximum signal, minimum risk — Prove the approach before tackling bigger problems.

Key Decisions

Constraints
1

Couldn't fix the AI itself

Responses were terrible. Model accuracy was the real bottleneck.

2

Backend architecture

Built as if assistant lived outside the app. Couldn't see page context.

3

Sidebar couldn't ship

Design system gaps. Dependencies on other teams. This frustration led to PAX.

Solution

Control + Errors
1

Stop button

Interrupt responses anytime instead of waiting for completion.

2

Take action button

Navigate directly to relevant screen after an answer.

3

Error handling

Descriptive messages, timestamps, copyable for support.

Unresolved

The floating window still obstructed the UI. Sidebar exploration couldn't ship—design system gaps, dependencies on other teams. This frustration inspired PAX: a Chrome extension with the Sidepanel API.

19%→22%
CSAT improved by 16% (relative). Modest—model accuracy unchanged. But it proved: UX was no longer the bottleneck.

Impact

The Ripple
1

5-10 designers now ship code

Created documentation and tutorials. I'm no longer the only one.

2

Design org talk

VP of Design congratulated me in person. Designers approached me afterward.

3

New practice established

Designers building AI must understand how the AI works.

"It's not how it looks—it's how it works."

Designers building AI must understand:
Where does AI get context? How does it find information? What surfaces need design?

"If you're looking at the answer and the AI can't see it, it's not artificially intelligent—it's real dumb."

The assistant couldn't answer questions when the answer was on the page.
That's what motivated PAX.

What's Next
