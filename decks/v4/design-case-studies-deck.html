Drawbridge

How I built a Chrome Extension to streamline visual edits for AI-Driven development

Project
Drawbridge (Personal Project)
Role
Designer & Engineer
Timeline
June 2025–Current

Customer

I design, build and ship

  • AI accelerates this process
  • But I inevitably have to tweak something
  • My process was breaking down with front-end tweaks

Problem

Describing changes is a problem

  • I created screenshots
  • Annotated them with arrows
  • Described the changes
  • But LLM wouldn't always get it

Hypothesis

What if I could leave a comment?

  • Leave comments "on" the website
  • Provide element context directly to AI
  • Do this from a plugin so I can keep my existing workflow
  • Manage them like a tasklist

My solution

How Drawbridge works

Process

Connect to a local file

  • Creates a local file that stores your changes
  • Nothing is sent to the cloud
  • Only use AI in your IDE

Process

Leave comments for Cursor

A familiar UX pattern for an AI teammate

Process

Draw a rectangle

Capture multiple objects on the page

Process

Engineering the workflow

Create richer context that require less verbose comments

  • Spins up task-list.md, task-list.json and screenshots folder
  • Each comment writes to all three: natural language prompt + JSON structure + screenshot ID
  • Bounds for rectangle are also included

Process

Type "bridge" to read edits and make changes

Automated workflow steps through tasks and reads context

Process

Changes are visible in the browser

  • Reduces back and forth
  • Maximizes context window for token usage
  • Helps to remain in flow state

Result

10x Faster iteration
One change took 2–3 minutes. Now 10 changes takes 2–3 minutes.
