An expense-tracking app landing page where the motion is the point: hero
loops, feature clips, and an app-flow walkthrough all rendered from React
components rather than exported from a video editor.

Worth doing to find out where "design in code" stops being a slogan —
timeline work in a text editor is genuinely better for iteration and
genuinely worse for feel.
